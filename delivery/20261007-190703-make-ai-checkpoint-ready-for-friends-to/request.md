Add a 'For testers' section to the README with: prerequisites (uv, git), uv install commands for Mac and Windows, ready-to-paste config for Claude Desktop (Mac and Windows config file locations), Claude Code (claude mcp add -s user ...) and Cursor (~/.cursor/mcp.json, %USERPROFILE%\.cursor\mcp.json), a note to use the full path to uvx if the app can't find it, a 2-minute test (save then resume in a new chat), where checkpoints are stored, and how to send feedback. Repo URL placeholder: https://github.com/<owner>/ai-checkpoint. Out of scope: hosting, HTTP transport, GitHub storage, PyPI publishing, Linux-specific docs.

Note from the orchestrator: the store's lock already falls back to a no-op where fcntl is missing (store.py _lock), so check what actually breaks on Windows rather than assuming; a real Windows lock (msvcrt) is preferred over a no-op. Test the uvx install against a local git URL (git+file://...) since the GitHub repo does not exist yet; uv is installed in the sandbox.
