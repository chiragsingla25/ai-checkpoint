This needs DESIGN-v2 §7's sentence "`depends_on` refers to tasks in the same list by the id they will receive" changed; ask the orchestrator to log it. The alternative, rewording the tool description to explain the offset, is harder for a small model to follow and needs the parent's highest id in front of the model.
