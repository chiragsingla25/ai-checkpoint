# Request

Build the AI Checkpoint MVP described in docs/MVP.md (sections 4, 5, 15, 16 and 30), using the research in docs/research.md. Python, local-first, standard library for the engine. Scope: Phases 1-5 with Claude Code as the first provider (capture from its JSONL transcripts, continuous via hooks), a provider-independent universal conversation format, checkpoint engine with JSON storage in .ai-checkpoint/, one git commit per checkpoint in that folder's own repo, resume-context generation that a new conversation can paste or receive via a SessionStart hook, a CLI matching section 30 (init, capture, save, list, show, resume), and an MCP server exposing save_checkpoint, list_checkpoints, get_checkpoint and resume_checkpoint as an optional extra. Security per section 27: never commit secrets; redact obvious API keys/tokens from captured content. Out of scope: section 6 items, Codex/ChatGPT adapters, artifact support (Phase 6), automatic structured-state extraction with an LLM.
