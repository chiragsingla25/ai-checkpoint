# Request

Make AI Checkpoint easy to run locally on the user's Mac (macOS, pyenv Python, Claude Desktop app + Claude Code). (1) Add MCP server instructions (the SDK's server-level instructions) telling clients: when the user asks to checkpoint/save this chat or resume/continue a checkpoint (e.g. 'resume trial/test-v1'), use these tools; how to pick chat_name/checkpoint_name; and on resume, read the brief and confirm the current step. In a test session, a real Claude Code session searched git and files for 'resume trial/test-v1' instead of calling the tool. (2) A one-command setup script scripts/setup-mac.sh, run from the repo, that: creates/updates a venv in the repo (.venv, needs Python >= 3.10, clear error otherwise), installs the package with the mcp extra, registers the server for Claude Code at user scope using the venv's absolute ai-checkpoint-mcp path and AI_CHECKPOINT_HOME=/root/.ai-checkpoint (removing any earlier local-scope 'ai-checkpoint' entry; skips with a message if the claude CLI is missing), and adds/updates the 'ai-checkpoint' entry in ~/Library/Application Support/Claude/claude_desktop_config.json (backup first, preserve other servers and keys, create the file if missing), then prints next steps (restart Claude Desktop, /mcp to verify, a first save/resume test). Idempotent; supports --dry-run and a config-path override for testing. README quick start updated. Out of scope: HTTP transport, hosting, GitHub storage, OAuth.
